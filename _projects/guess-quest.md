Guess Quest is a higher-or-lower card game. Guess whether the next card is higher or lower; streaks multiply the score.

I built it in a single day as a scope exercise — Unity 2022.3, C#, and a public GitHub repo. That is the whole pitch. It is a finished prototype, not a live-service title.
